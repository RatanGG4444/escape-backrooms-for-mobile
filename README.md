# 🎮 Escape The Backrooms - Pure HTML5

A multiplayer survival horror game built with pure HTML5, CSS3, and JavaScript. **No Unity required!**

## 🌟 Features

- ✅ Pure HTML5/JavaScript - runs in any modern browser
- ✅ Multiplayer support (up to 4 players)
- ✅ 4 procedurally generated levels
- ✅ 5 unique AI entities
- ✅ Real-time 3D raycasting graphics
- ✅ Sanity & health system
- ✅ Flashlight mechanics
- ✅ Mobile-responsive controls
- ✅ **NO DOWNLOADS REQUIRED**
